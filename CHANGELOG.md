# Changelog

## v0.1.0 - 2026-10-21

First public version: the MVP and its product and team pack.

- Intake of partial requests with questions for every gap (US-01); category chosen or inferred (US-02)
- Method from a procurement-owned policy with the rule shown (US-03); framework call-off before competition (US-04); 12-month total and split-purchase flag (US-05); justification for a named supplier (US-06)
- TOR drafted from the template with nothing invented (US-07); completeness checklist (US-08)
- Human checkpoints and four eyes enforced in code, with a procurement-owned role roster and a note required to approve a flagged case (US-09); request text treated as data (US-10)
- Request package as Markdown, HTML and JSON with the agent's audit trail (US-11); usage events in the ai-adoption-tracker format (US-12)
- Product pack (discovery, service blueprint, options and investment case, PRD, WSJF roadmap and PI objectives, human control, adoption plan, metrics and pilot, decision log) and team pack (brief, RACI, backlog, iteration plan, working agreement); CI enforces that every Done story has a test
